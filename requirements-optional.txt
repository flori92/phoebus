# ── Wake Word "Hey Jarvis" — 100% gratuit ────────────────────────────────────
#
# Option 1 (recommandée) : OpenWakeWord — MIT, modèles ONNX pré-entraînés
#   pip install openwakeword onnxruntime
#   → modèle "hey_jarvis" téléchargé automatiquement
#
# Option 2 : Vosk — Apache 2.0, STT offline avec keyword spotting
#   pip install vosk
#   → Télécharger le modèle FR (40 Mo) :
#   curl -LO https://alphacephei.com/vosk/models/vosk-model-small-fr-0.22.zip
#   unzip vosk-model-small-fr-0.22.zip
#   → Ajouter JARVIS_VOSK_MODEL_PATH=./vosk-model-small-fr-0.22 dans .env
#
# Option 3 : Pocketsphinx — BSD, ultra-léger (~1 Mo), keyword spotting natif
#   pip install pocketsphinx
#   → Aucune config supplémentaire requise
#
# ⚠️  PICOVOICE/PORCUPINE A ÉTÉ RETIRÉ : gratuit non-commercial seulement,
#     compte requis, risque de changement tarifaire. Utiliser OWW ou Vosk.
